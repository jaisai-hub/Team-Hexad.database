## Project

### AI-Based Oil Spill Detection and Vessel Analysis

An AI-based system that combines Sentinel-1 SAR satellite imagery, deep learning, ocean and weather data, particle tracking and AIS vessel data.

Main components:

* Oil spill detection using ResNet-34 and U-Net
* Spill segmentation and GeoJSON generation
* Oil spill drift prediction
* Probable spill origin estimation
* AIS vessel trajectory reconstruction
* Vessel filtering and ranking
